# ⚡ SIDD-Reacts

> **Next-Gen Animated React Components & Kinetic Visual Effects Engine**  
> Crafted with Framer Motion, Tailwind CSS, HTML5 Canvas, and TypeScript.

---

## 🌟 Features

- 💎 **Dark Minimalist Aesthetic:** Sleek obsidian background (`#060608`), glowing radial meshes, and typography.
- ⚡ **60 FPS Hardware Physics:** Framer Motion spring interpolation and optimized HTML5 Canvas simulations with automatic lifecycle cleanup.
- 🧰 **CLI Tooling (`npx sidd-reacts`):** Install components directly into your codebase with one command.
- 🎛️ **Live Parameter Controls:** Real-time sliders, color pickers, and toggles wired to component props.
- 💻 **Syntax Highlighting & Code Inspector:** Prism-highlighted TSX/JSX snippets with line numbers and copy feedback.
- 🖥️ **Full-Screen & PC Mockup Previews:** Responsive stages with background switchers (Dark Grid, Dot Matrix, Pitch Black, Radial Glow).

---

## 🚀 Quick Start with CLI

You can add any component directly into your React / Next.js / Vite project using `npx`:

```bash
# Add Spotlight 3D Card
npx sidd-reacts add spotlight-card

# Add Particle Vortex Canvas
npx sidd-reacts add particle-vortex

# Add True Focus Text
npx sidd-reacts add true-focus

# List all available components
npx sidd-reacts list
```

## 🛠️ Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/<your-username>/sidd-reacts.git
   cd sidd-reacts
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start local dev server:**
   ```bash
   npm run dev
   ```

4. **Build production bundle:**
   ```bash
   npm run build
   ```
